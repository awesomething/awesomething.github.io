Andrew Ng's 2-Hour Course on Graph Engineering: 1 Prompt to 100 Agents

Summary

Andrew Ng's 2-hour course covers graph engineering — going from a single prompt to 100 agents, loops, and graphs.

(00:00–03:24) Agentic workflows outperform one-shot prompting

Andrew Ng explains that instead of asking an LLM to generate a complete answer in one pass, AI systems perform better when they plan → research → draft → critique → revise. These iterative loops produce higher-quality outputs and can even generate better synthetic training data for future models.

(03:24–08:49) The five core design patterns of AI agents

The course introduces the fundamental building blocks of modern agent systems: planning (breaking tasks into steps), tool use (search, APIs, calculators, etc.), reflection (self-critique and revision), multi-agent collaboration (specialized agents working together), and memory (tracking state across many steps). LangGraph represents these workflows as graphs with loops instead of simple linear chains.

(08:49–28:31) Building a ReAct agent and understanding LangGraph fundamentals

Harrison Chase demonstrates building an agent from scratch before rebuilding it with LangGraph. Key LangGraph concepts include nodes (LLMs or functions), edges (transitions between nodes), conditional edges (decision points), and agent state (shared memory carried through the graph). The course shows how agents decide whether to call tools or finish execution based on the current state.

(28:31–56:24) Search is an agent's most important tool

The course explains why agentic search differs from traditional search engines. Instead of returning web pages, agent-oriented search returns structured, machine-readable results that agents can immediately reason over. Examples show parallel tool calls (checking SF and LA weather simultaneously) and sequential reasoning (finding the Super Bowl winner first, then querying that state's GDP).

(56:24–1:10:35) Persistence and streaming make agents production-ready

LangGraph introduces checkpointing after every node, persistent conversation threads, state restoration, token streaming, and event streaming. This enables long-running workflows, multiple concurrent users, and agents that remember previous conversations.

(1:10:35–1:25:19) Human-in-the-loop, interrupts, and "time travel"

One of LangGraph's most powerful capabilities is pausing execution before important actions. Developers can approve or reject tool usage, edit an agent's planned action, modify stored state, or resume execution from any previous checkpoint. The course refers to replaying previous checkpoints as "time travel," making debugging and production oversight much easier.

(1:25:19–1:43:38) Building a multi-agent essay writer

A complete project demonstrates an autonomous research and writing pipeline: a planner creates an outline, a research agent gathers information, a writer drafts the essay, a critic reviews weaknesses, the research agent gathers missing information, the writer revises, and the loop repeats until stopping criteria are met. This showcases how graph-based workflows naturally support iterative improvement.

(1:43:38–1:49:57) LangGraph ecosystem and production tooling

The instructors recommend LangChain for higher-level abstractions, LangGraph for workflow orchestration, LangSmith for debugging, tracing, monitoring, and evaluation, and Prompt Hub, templates, and LangServe for deployment. The emphasis is on building controllable production AI rather than isolated prompt chains.

(1:49:57–End) Future of agent architectures

The course concludes by surveying advanced patterns: multi-agent systems with shared state, supervisor agents coordinating specialized subagents, flow engineering (AlphaCodium-style workflows), plan-and-execute architectures, and Language Agent Tree Search (LATS). The central message is that future AI applications will be designed as graphs of collaborating agents rather than single prompts, giving developers precise control over reasoning and execution.
